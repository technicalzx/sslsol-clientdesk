# Community code of conduct

Treat people respectfully. Welcome questions and contributors with different experience, identities and backgrounds. Discuss ideas and code without personal attacks, harassment, discrimination or intimidation.

Protect privacy: do not post credentials, private targets, client records, personal contact details or confidential screenshots. Use synthetic examples in issues and pull requests. Ask permission before sharing someone else's work or information.

Maintainers may edit or remove harmful material, close abusive discussions and restrict participation when needed. They should explain moderation decisions when doing so will not expose private information. Apply these expectations consistently and allow good-faith corrections.

For a conduct concern, contact a repository maintainer through a verified private channel. Do not publish private allegations or contact details in an issue. A dedicated reporting address will be listed only after it is verified by the owner.

This applies to project issues, pull requests, discussions and other project spaces. Security vulnerability reports follow SECURITY.md.
